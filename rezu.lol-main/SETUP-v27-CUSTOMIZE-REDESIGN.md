# v27 Customize Redesign

No SQL migration is required for this update.

## What changed
- Rebuilt the Customize page into a guns.lol-inspired control layout while keeping rezu.lol branding.
- Red/black/gray/white dashboard styling.
- Added a sticky live profile preview directly on Customize.
- Assets Uploader is grouped at the top.
- General Customization groups profile content, Discord presence, opacity, blur, effects, layout, and avatar shape.
- Music & Cards groups GitHub, Spotify, and page-enter text.
- Color Customization groups all profile colors and gradient controls.
- Other Customization groups toggles, cursor effect, and font.
- Existing upload, audio, Discord, Spotify, badge-color, gradient, layout, and tag functionality is preserved.

## Deploy
1. Replace your current project with this build.
2. Keep your existing environment variables.
3. Redeploy on Vercel.

Optional local check:

```bash
npm install
npm run build
```
