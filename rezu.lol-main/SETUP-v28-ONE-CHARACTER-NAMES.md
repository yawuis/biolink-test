# v28 — One-character usernames/aliases

1. Replace/deploy this project build.
2. In Supabase SQL Editor run `supabase/v28-one-character-handles.sql` once.
3. One-character handles such as `/a`, `/7`, or `/_` are now valid.
4. Usernames and aliases still share the same global namespace, so a one-character handle can only belong to one account total.
